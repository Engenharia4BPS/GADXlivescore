## Classification

### CONFIRMED

- The six requested paths returned `200 application/json` in this bounded POC.
- The documented read paths were reachable without explicit credentials in this
  sample.

### OBSERVED

- Discovery uses `dat`, day, and time fields rather than `startdate`/`enddate`.
- Category records contain code/display pairs and sentinel values.
- `displayscore` can contain historical station timestamps; row presence is not
  evidence of current activity.
- `soft` has heterogeneous types and `auth` is present as a string field.
- Aggregate totals and visible per-band values are not universally equivalent.

### INFERRED

- `qtotal`, `ptotal`, and `mtotal` should be preserved as source-authoritative
  values instead of recomputed from the observed band fields.

### UNRESOLVED

- `dat` encoding, year, timezone, and conversion to absolute contest windows.
- Source timestamp timezone, category-code semantics, and `qtotal*` semantics.
- Active-contest classification, rate limits, cache behavior, pagination, and
  stale-row lifecycle behavior.
